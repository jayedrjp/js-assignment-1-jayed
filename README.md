## Tasks

The assignment contains the following tasks:

1. Calculate money returned by the shopkeeper.
2. Calculate the average marks of five subjects.
3. Find the remainder after dividing a number by 5.
4. Explain the results of `isNaN()`.
5. Calculate BMI and determine the health category.
6. Calculate a student's grade.
7. Determine an action based on my score and my friend's score.
8. Calculate a result using if-else and ternary operators.
9. Calculate ticket fare based on age and student status.
